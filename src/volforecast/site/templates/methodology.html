Methodology

Each trading evening the bot forecasts the variance of the next session's close-to-close log return for SPY, QQQ, IWM, TLT and GLD, plus the 1-day Value-at-Risk at 95% and 99%. Forecasts are committed to an append-only branch before the next open, stamped with an OpenTimestamps proof, and scored the following evening.

What is scored

Returns are log returns from unadjusted prices plus dividend and split records. The “what actually happened” proxy is the squared overnight return plus the Rogers–Satchell intraday variance; squared returns and a Garman–Klass version are robustness checks. The primary loss is QLIKE, which keeps model rankings valid when the proxy is noisy (Patton, 2011).

Models

Baselines: random walk, 21-day mean proxy, 21-day Yang–Zhang, and RiskMetrics EWMA (λ = 0.94). Statistical models: GARCH(1,1) with normal and Student-t errors, GJR-GARCH, EGARCH, a short-history GARCH that shrinks toward typical parameter values (penalized likelihood), and HAR on log proxies. An equal-weight ensemble averages the statistical models that forecast that evening. For SPY, the VIX and a recalibrated VIX are compared too. All models use a zero daily mean.

VaR

VaR = −√h · q, where q is the quantile of the model's standardized distribution: normal, unit-variance Student-t, or, for one GARCH variant, the empirical quantile of past standardized residuals (filtered historical simulation). A violation is a return below −VaR. Violation flags are published; returns are not.

Honesty rules

  • No forecast uses information from after its forecast time; the backtest calls the same code as the live job.
  • Forecasts are never edited. Late forecasts are kept but excluded from the live record.
  • Every statistic shows its sample size. Comparisons are “early” before 60 live sessions; VaR tests are “low power” until 10 violations are expected.
  • Model versions are fixed. Any change that could alter outputs starts a new version with its own record.

Data and licensing

Prices: Alpha Vantage (free tier, non-commercial use). Raw prices, volumes and returns are never published; they stay in a private repository. VIX: Cboe, via FRED. S&P 500 index (backtest only): S&P Dow Jones Indices, via FRED. Only derived statistics appear here.
